# Ground Manager Pro website

Product and release website for Ground Manager Pro, built with Next.js, React, TypeScript, and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The interactive app preview is a simulated website demo; it does not connect to a simulator or send ground-service commands.

## Verification

```bash
npm run typecheck
npm run lint
npm run build
```

## Release downloads

The website shows the v1.4.1 release information, but download buttons remain disabled until official installer files and a release URL are supplied. File sizes and SHA-256 checksums are not fabricated.
